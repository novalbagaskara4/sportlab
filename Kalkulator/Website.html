Laporan Analisis

Panduan Penggunaan

1. Menghitung VO2Max

  1. Isi data atlet (nama, jenis kelamin, usia)
  2. Masukkan Best Time atlet (jarak dan waktu)
  3. Masukkan hasil tes 12 menit dan 15 menit
  4. Klik "Hitung VO2Max"
  5. Simpan hasil ke database

2. Mengelola Database

Di menu Database, Anda dapat:

  • Melihat semua atlet yang tersimpan
  • Mencari atlet tertentu
  • Mengedit atau menghapus data
  • Mengekspor data ke file CSV

3. Membuat Laporan

Di menu Laporan, Anda dapat:

  • Generate laporan statistik
  • Filter berdasarkan periode waktu
  • Melihat analisis performa atlet
  • Mencetak laporan

4. Standar VO2Max

Batas kelayakan untuk seleksi atlet KU-2:

  • Laki-laki: ≥ 55.4 mL/Kg/menit
  • Perempuan: ≥ 45.1 mL/Kg/menit

Tentang Aplikasi

SportLab VO2Max Calculator

Aplikasi ini dikembangkan untuk membantu proses seleksi atlet renang kelompok usia 13-15 tahun (KU-2) berdasarkan kapasitas VO2Max.

Fitur Utama

  • Perhitungan VO2Max berdasarkan velocity
  • Database penyimpanan data atlet
  • Sistem laporan analisis
  • Standar kelayakan sesuai pedoman Kemenpora

Metodologi

Perhitungan didasarkan pada laporan penelitian "Pengembangan Standardisasi Kapasitas VO2max Sebagai Tolok Ukur Seleksi Atlet Renang KU-2" yang menggunakan velocity sebagai parameter utama.
