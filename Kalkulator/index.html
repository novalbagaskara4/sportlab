Tentang Aplikasi

SportLab VO2Max Calculator adalah aplikasi web yang dikembangkan khusus untuk membantu pelatih dan pembina olahraga dalam proses seleksi atlet renang kelompok usia 13-15 tahun (KU-2). Aplikasi ini menggunakan metode perhitungan berbasis velocity sesuai standar Kemenpora RI.

Kompatibilitas

✓ iOS (iPhone, iPad) - Safari, Chrome
✓ Android - Chrome, Firefox, Samsung Internet
✓ Desktop - Chrome, Firefox, Edge, Safari
✓ Tidak perlu install - Bekerja langsung di browser

Cara Menyimpan ke Home Screen

iPhone/iPad: Buka aplikasi → Tekan tombol share → "Tambahkan ke Home Screen"
